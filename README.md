# Python Text Analyzer

A lightweight and efficient Python tool designed to analyze text, count total words, characters, and check individual word frequencies.

## Features
- **Text Statistics**: Instantly calculates total word count and character count.
- **Word Frequency Analysis**: Counts how many times each word appears in the given text.
- **Clean Python Fundamentals**: Built using strings, dictionaries, loops, and built-in functions.
